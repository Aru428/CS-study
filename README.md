# CS-study

백엔드 개발에 필요한 CS 개념을 하루 한 주제씩 정리하는 저장소입니다.

## 정리 방식

- 하루 한 주제, 30분
- 개념 정의 → 왜 필요한가 → 동작 방식 → 직접 확인한 것 → 헷갈렸던 점 순서로 씁니다
- 가능하면 직접 실행해 보고(쿼리, 명령어, 코드) 그 결과를 함께 남깁니다
- 형식은 [TEMPLATE.md](TEMPLATE.md)를 따릅니다
